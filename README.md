# Nikita's Natural static website

This is a standalone HTML/CSS/JavaScript reconstruction of the public Nikita's Natural pages.

## Structure
- `index.html` — Home
- `shop.html` — Shop and product filters
- `about.html` — Founder and process
- `contact.html` — Contact and WhatsApp link
- `css/styles.css` — Responsive styling and animations
- `js/script.js` — Mobile navigation, filtering, scroll reveal
- `assets/` — Replace the placeholder filenames with downloaded copies of the original images from the Hostinger AI Builder Media Library.

## Deploy
Upload the contents of this folder to the web root, or commit it to GitHub and deploy the repository as a static site. No build command is required.

## Important
The original builder's checkout, form processing, product backend, fonts, and hidden settings are not exposed through the public pages. Product cards in this reconstruction are presentation-only until connected to an independent shop or form service.
